## Overview
ArcGIS Desktop for Windows is Esri's desktop GIS application, built for analysts, researchers, and agencies that need to edit geographic data, run spatial analysis, and publish finished maps. As a long-established piece of arcgis software, it bundles map authoring, geodatabase editing, and geoprocessing into one Windows application rather than requiring several separate tools.

## Features
* Author multi-layer maps from vector, raster, and tabular sources
* Run spatial analysis using the built-in geoprocessing toolbox
* Edit geodatabase features directly inside the application
* Import shapefiles, CAD drawings, and raster imagery
* Export finished map layouts for printing or sharing

## System Requirements
ArcGIS Desktop expects a 64-bit edition of a currently supported version of Windows running on a modern processor, with at least the amount of RAM Esri currently specifies for smooth performance on larger map documents, plus enough free disk space to cover installation and your ongoing project and geodatabase files.
